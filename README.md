# 🎼 Harmony and Discord

**Harmony and Discord** is a frontend portfolio project built as part of the **UNSW Web Development Society's Term 3 2024 Training Program**. Inspired by my background in classical piano, this project explores the contrast between *harmony* (major chords/songs) and *discord* (minor chords/songs) through interactive web design and sound.

## ✨ Features

### 🎵 Harmony Page
- A warm, welcoming UI
- Definition of musical *harmony*
- Interactive musical notes with audio playback
- A short, personal description of me
- A list of my favorite *happy* classical piano pieces

### ⚡ Discord Page
- Dramatic thunder animation at regular intervals
- Exploration of *discord* through minor chords
- Interactive minor musical notes with sound
- More chaotic (but equally beautiful) piano pieces
